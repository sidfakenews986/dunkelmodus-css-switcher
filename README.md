# Dunkelmodus CSS Switcher

## Beschreibung
Dieses Projekt bietet eine praktische Lösung zur Implementierung eines Dunkelmodus für Webanwendungen. Der Dunkelmodus CSS Switcher ermöglicht es Entwicklern, den Designstil ihrer Website je nach Vorliebe der Benutzer oder Tageszeit dynamisch zu ändern. 

## Features
- Einfache Integration in bestehende Projekte.
- Anpassbare Farbschemata für den Dunkel- und Hellmodus.
- Unterstützung von Cookies zur Speicherung der Benutzereinstellungen.
- Responsives Design für verschiedene Bildschirmgrößen.

## Installation
Um den Dunkelmodus CSS Switcher in Ihrem Projekt zu installieren, folgen Sie diesen Schritten:
1. Klonen Sie das Repository:
   ```bash
   git clone https://github.com/IhrBenutzername/dunkelmodus-css-switcher.git
   ```
2. Fügen Sie die CSS-Dateien in Ihre HTML-Datei ein.
3. Verwenden Sie den bereitgestellten JavaScript-Code, um den Modus umzuschalten.

## Verwendung
```html
<link rel="stylesheet" href="dunkelmodus.css">
<script src="dunkelmodus.js"></script>
```

Fügen Sie den Umschalter in Ihre UI ein:
```html
<button id="mode-toggle">Dunkelmodus umschalten</button>
```
